# Therapist Website

A modern, responsive therapist practice website built with **Next.js, TypeScript, and Tailwind CSS**.

The website is designed for **Dr. Maya Reynolds, PsyD**, with a warm and calming visual identity, therapist-focused content, service information, FAQs, and a custom office section.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern therapist-focused UI/UX
* Custom color theme and typography
* SEO-friendly page structure
* About Dr. Maya Reynolds section
* Therapy services and specialties
* Therapeutic approach section
* Frequently Asked Questions
* Custom **Our Office** section
* Contact / consultation form
* Reusable React components
* Dedicated pages for detailed information

## 🛠️ Tech Stack

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **Next.js Font**
* **Vercel** for deployment

## 🎨 Design

The website uses a warm, calming visual theme suitable for a therapy practice.

| Color    | Hex       | Usage         |
| -------- | --------- | ------------- |
| Clay     | `#96502F` | Primary / CTA |
| Moss     | `#4F5D46` | Secondary     |
| Linen    | `#FAF6F0` | Background    |
| Charcoal | `#2B2622` | Text          |
| Sand     | `#E8DCC8` | Accents       |

**Typography:** Fraunces for headings and Inter for body text.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/KapilYadav11/therapist-website.git
cd therapist-website
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## 🏗️ Production Build

```bash
npm run build
npm start
```
